# PhantomOperator examples

These examples use only public discovery and free evaluation routes. They do **not** send a payment or execute a paid operation. For paid calls, inspect the returned HTTP 402 requirement and use an x402-compatible Base-USDC client to sign and retry it.

- `metadata-preview.sh` — free, rate-limited metadata summary
- `x402-payment-quote.sh` — inspect the exact payment requirement for the $0.05 full audit
- `mcp-tools-list.sh` — list MCP tools through JSON-RPC

Do not submit information you are not authorized to assess.
